# じてんしゃ旅

自転車を組み立てて、服を選んで、日本の実在のルートを旅するブラウザゲームです。ノスタルジックなドット絵で、PCとスマホのブラウザで遊べます。

身内で遊ぶためのゲームなので、実在メーカーのパーツや服が登場します。価格や性能はゲーム用の目安です。

## 遊び方

ビルドは不要です。リポジトリのフォルダでローカルサーバーを立ててブラウザで開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages（Settings → Pages → Branch: main / root）を有効にすると、スマホからも URL で遊べます。

## 今できること

- 組み立て画面：自転車の部分をタップするか、タブを選んでパーツを付け外し
- 服えらび：ヘルメット、トップス、ボトムス、シューズ
- 速さ、軽さ、快適さ、丈夫さ、映えの5つの性能
- ルート選択（5コース）
  - しまなみ海道（尾道 → 今治、直進）：6つの橋と島
  - ビワイチ（琵琶湖一周、周回）：琵琶湖大橋、白鬚神社の鳥居、彦根城、メタセコイア並木
  - つくば霞ヶ浦りんりんロード（霞ヶ浦一周、周回）：蓮田、帆引き船、筑波山
  - 富士五湖（周回）：大きな富士山、峠ののぼり、ラベンダー
  - 東京 → 箱根（直進）：国道15号の街なか、湘南の海岸、江の島、小田原城、箱根の峠と温泉
- 走行画面：横スクロールで走る。時刻で空の色が変わり、夕焼けや夜になる。長いルートは早送り（×2／×3）できる
  - ペース（ゆっくり／ふつう／がんばる）で速さと体力の減り方が変わる
  - 橋の手前はのぼり坂、風向き、パンク（丈夫さで起きやすさが変わる、連打で修理）
  - 島ごとの名物を食べて体力回復
  - 撮影スポットでシャッターのタイミングを合わせて写真を撮ると「いいね」がもらえる（映えと時間帯で増える）
  - 直進ルートはゴールで輪行（電車やバス）で帰るか、走って帰るかを選ぶ
  - 箱根では温泉に入って体力を大きく回復
- SNS：旅で撮った写真は自動で投稿され、1いいね20円の収入。フォロワーが増えると次から「いいね」が付きやすくなる
- サイクルショップ：GIOS、COLNAGO、Cervélo、Campagnolo、Castelli、Levi's など、新品のパーツと服を、作業場の自転車で試してから買える
- リサイクルショップ：日替わりの品ぞろえで新品の5〜7割。たまに3割前後の掘り出し物。持っているものを売ることもできる
- バイト（ミニゲーム）
  - 自転車屋でパンク修理：タイヤレバー、泡で穴探し、空気入れをタイミングよく
  - フードデリバリー：自分の自転車で配達。速さと丈夫さが効き、障害物はジャンプでよける
- 旅やバイトをすると1日進む
- セーブはブラウザに自動保存

## ファイル

- `index.html`, `style.css`：画面
- `src/data.js`：パーツと服のデータ
- `src/draw.js`：自転車と人のドット絵描画
- `src/state.js`：セーブと性能計算
- `src/routes.js`：ルートと区間（橋、島、名物、撮影スポット）
- `src/ride.js`：走行のシミュレーション
- `src/scenery.js`：走行画面の景色
- `src/rideScreen.js`：走行画面の操作と表示
- `src/economy.js`：SNSの収益、リサイクルショップの品ぞろえ
- `src/store.js`：ショップ、リサイクルショップ、SNSの画面
- `src/jobs.js`：バイトのミニゲーム
- `src/main.js`：画面の切り替えと操作
