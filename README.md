# じてんしゃ旅

自転車を組み立てて、服を選んで、日本の実在のルートを旅するブラウザゲームです。ノスタルジックなドット絵で、PCとスマホのブラウザで遊べます。

身内で遊ぶためのゲームなので、実在メーカーのパーツや服が登場します。価格や性能はゲーム用の目安です。

## 遊び方

ビルドは不要です。リポジトリのフォルダでローカルサーバーを立ててブラウザで開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages（Settings → Pages → Branch: main / root）を有効にすると、スマホからも URL で遊べます。

## 今できること

- 組み立て画面：自転車の部分をタップするか、タブを選んでパーツを付け外し
- 服えらび：ヘルメット、トップス、ボトムス、シューズ
- 速さ、軽さ、快適さ、丈夫さ、映えの5つの性能
- ルート選択：しまなみ海道（尾道 → 今治）
- 走行画面：6つの橋と島を横スクロールで走る。時刻で空の色が変わり、夕焼けや夜になる
  - ペース（ゆっくり／ふつう／がんばる）で速さと体力の減り方が変わる
  - 橋の手前はのぼり坂、風向き、パンク（丈夫さで起きやすさが変わる、連打で修理）
  - 島ごとの名物を食べて体力回復
  - 撮影スポットでシャッターのタイミングを合わせて写真を撮ると「いいね」がもらえる（映えと時間帯で増える）
  - ゴールで輪行（バス）で帰るか、走って帰るかを選ぶ
- セーブはブラウザに自動保存

## ファイル

- `index.html`, `style.css`：画面
- `src/data.js`：パーツと服のデータ
- `src/draw.js`：自転車と人のドット絵描画
- `src/state.js`：セーブと性能計算
- `src/routes.js`：ルートと区間（橋、島、名物、撮影スポット）
- `src/ride.js`：走行のシミュレーション
- `src/scenery.js`：走行画面の景色
- `src/rideScreen.js`：走行画面の操作と表示
- `src/main.js`：画面の切り替えと操作
